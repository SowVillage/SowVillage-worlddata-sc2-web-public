# Minecraft textures

The selected block textures are from Mojang's official [Bedrock samples](https://github.com/Mojang/bedrock-samples), revision `46ba6ea985fb5a92d79a9419198f10dda14c199d`.

This viewer uses only textures referenced by the archived world's real block palette. A generated 16-pixel atlas combines those files, adds a one-pixel border, applies a fixed foliage/water color, and selects the first frame of animated textures. Source files, their exact URLs, sizes and SHA-256 checksums are retained in the offline `SowVillage-worlddata-sc2-workbench/assets/bedrock-samples/sources.json`; the public data repository contains only serving assets and attribution.

The material mapping preserves legacy wall variants and resolves directional faces from the archived block states. Direction values follow Microsoft's [official block state reference](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/blockreference/examples/blockstateandtraitlistings?view=minecraft-bedrock-stable). Six additional textures from the same pinned Mojang revision represent open barrels, full bee nests and beehives, powered observers, sticky piston heads, and lit pumpkins. Existing atlas tile numbers are preserved; the extra textures occupy previously unused tiles.

Special plants resolve the official registry's resource-selection slots into model parts: bamboo stems and state-selected leaves, tall seagrass halves, kelp bodies and tips, and sunflower disks. Crop stages, berry growth, curved rails and powered rails use the archived states. The Bedrock-to-Java state conversion in [je2be-core](https://github.com/kbinani/je2be-core/blob/ff90bef48c957c3da2a39321553a86fd920268db/src/bedrock-block-data.cpp) and the vanilla model/state data maintained by [PrismarineJS](https://github.com/PrismarineJS/minecraft-assets/tree/c4901c50d9da6e011413fcd9f54cde7f63a2c3bd/data/1.16.4) were consulted as references; no code from those projects is included in these serving assets. Two nether-wart stage textures and sunflower front/back textures come from the same pinned Mojang revision. Fern textures receive the same fixed foliage color as other tinted plants. Seven atlas tiles were appended in a new row; all previous tile numbers and pixels remain unchanged.

Decorative blocks use the native sign, colored bed, single/double/ender chest, skull/dragon, bell and book entity sheets from the same pinned Mojang revision. Their model faces are cropped into appended atlas tiles; all earlier tile numbers and complete pixel borders are preserved. Banner masks retain their native 20×40 cloth area, including the ominous banner artwork. The original map paper texture fills unexplored map pixels. Framed item icons follow the saved item variants and legacy block states, including wood species and colored blocks. Exact source URLs, source checksums and crop coordinates remain in the offline workbench; no parsing or build code is published here.

The native sheets and masks are available in Mojang's pinned [entity textures](https://github.com/Mojang/bedrock-samples/tree/46ba6ea985fb5a92d79a9419198f10dda14c199d/resource_pack/textures/entity), [item textures](https://github.com/Mojang/bedrock-samples/tree/46ba6ea985fb5a92d79a9419198f10dda14c199d/resource_pack/textures/items), and [map paper texture](https://github.com/Mojang/bedrock-samples/blob/46ba6ea985fb5a92d79a9419198f10dda14c199d/resource_pack/textures/map/map_background.png). Their copyright and EULA conditions are unchanged.
